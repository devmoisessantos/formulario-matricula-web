# Stage 01: Estrutura Inicial do Projeto

### 1. Inicializar o Repositório Git

Primeiramente, inicie o repositório Git no diretório do projeto:

```sh
git init .
```

### 2. Criar a Estrutura Base do Projeto

Crie as pastas necessárias para organizar os recursos e o código:

```sh
mkdir assets/images/icons, css
```

### 3. Adicionar Arquivos de Estrutura

Em seguida, crie os arquivos essenciais para a estrutura do projeto:

```sh
# Para o diretório CSS
cd css ; ni global.css ; ni styles.css

# Volte para o diretório raiz e crie os outros arquivos
cd .. ; ni index.html ; ni README.md ; ni .gitignore
```

### 4. Adicionar Alterações ao Stage Area e Realizar o Primeiro Commit

Adicione os arquivos ao stage e faça o primeiro commit:

```sh
git add .
git commit -m "first commit; estruturando o projeto"
```
